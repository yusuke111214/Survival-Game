# 最終課題製作物

## 概要
このゲームは、3Dのスカベンジシーンで資源を集め、シェルターシーンで家族の生存を管理するサバイバルシミュレーションゲームです。プレイヤーは探索、資源収集、イベント選択、そしてシェルター内での家族の健康管理や資源配分といった多層的なゲームシステムを体験します。

## 自作スクリプトについて
本プロジェクトにおける自作スクリプトはAssets/App/配下のScriptsファイルに格納されているすべてのスクリプトが自作のものとなります。

## シーン構成
- **スカベンジシーン**  
  3D環境でプレイヤーが資源を探索・収集するシーンです。プレイヤー操作、カメラ制御、アニメーション制御などが実装されています。

- **シェルターシーン**  
  スカベンジシーンで獲得した資源を用いて家族の生存を管理するシーンです。日々のイベント処理、資源の供給、家族の健康状態の管理、そしてナラティブの進行（DiaryManagerによるパネル制御など）が特徴です。
